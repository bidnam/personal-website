# Bidnam Lee - Portfolio Website

Personal portfolio featuring an interactive 3D terrain navigation built with Three.js.

## Concept

The "rugged landscape" metaphor from strategy (navigating complex competitive terrain) becomes a literal interface. Each peak represents a section of the site - hover and click to explore.

## Features

- Interactive 3D terrain with low-poly aesthetic
- Drag to rotate, arrow keys to navigate
- Hover effects with terracotta glow
- Auto-rotation when idle
- Responsive design

## Development

No build step required. Just open `index.html` in a browser.

```bash
# Optional: run local server
python3 -m http.server 8000
```

## Deployment

Static files - deploy to GitHub Pages, Netlify, Vercel, or any static host.

## Tech

- Three.js for 3D rendering
- Custom GLSL shaders for terrain coloring
- Vanilla HTML/CSS/JS
